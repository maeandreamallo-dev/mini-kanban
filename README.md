# MiniKanban

A lightweight full-stack Kanban task management application built with *Python, FastAPI, SQLAlchemy, SQLite, and vanilla JavaScript*.

MiniKanban demonstrates practical software engineering fundamentals including REST API development, database persistence, validation, automated testing, frontend integration, and containerization.

---

## Features

- Create Kanban tasks
- View all tasks
- View individual tasks
- Update task information
- Change task status
- Delete tasks
- Task priority levels
- Task validation
- Task pagination
- SQLite database persistence
- RESTful API
- Interactive web interface
- Automated API tests
- Docker support

## API Endpoints

Method  Endpoint                Description
GET     /health                 Health check
POST    /tasks                  Create a task
GET     /tasks                  List tasks
GET     /tasks/{task_id}        Get a task
PUT     /tasks/{task_id}        Update a task
PATCH   /tasks/{task_id}/status Change task status
DELETE  /tasks/{task_id}        Delete a task

Interactive API documentation is automatically generated by FastAPI.

Once the application is running:
    http://localhost:8000/docs

    description
    status
    priority
    created_at
    updated_at

Status

    TODO
    IN_PROGRESS
    REVIEW
    DONE

Priority
    low
    medium
    high

## Installation
1. Clone the repository
    git clone <repository-url>
    cd mini-kanban
2. Create a virtual environment
    python3 -m venv .venv
3. Activate the environment
    source .venv/bin/activate
4. Install dependencies
    pip install -r requirements.txt

---
## Running the Application
Start the FastAPI server:
    python -m uvicorn app.main:app --reload
The application will be available at:
    http://localhost:8000
API documentation:
    http://localhost:8000/docs

##Design Decisions

FastAPI
FastAPI provides a lightweight framework for building typed REST APIs with automatic OpenAPI documentation and request validation.

SQLAlchemy
SQLAlchemy provides an ORM layer that separates database operations from API routing logic.

SQLite
SQLite keeps the project simple and portable while providing real database persistence.

Pydantic
Pydantic models validate API input and enforce supported task statuses and priorities.

Dependency Injection
FastAPI dependency injection is used to provide database sessions to API endpoints.

Automated Testing
The application uses an isolated in-memory SQLite database during testing to prevent tests from modifying the development database.

         ↓
